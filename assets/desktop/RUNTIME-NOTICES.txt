This runtime includes no NumPy, SciPy, scikit-learn, Matplotlib, pandas,
NASA processing scripts, partner images, raw NLSP or credentials.
It includes data-only JSON weights for two small random forests trained locally
with scikit-learn on NASA SOTERIA ECG. Standard-library code performs inference;
the numerical training libraries are not bundled. One target is deliberately
injected technical corruption; the second is the authors' heartbeat-detector
exclusion annotations. The latter failed held-out evaluation. Both outputs on
real recordings are experimental scores for manual review, not calibrated
artifact probabilities, clean-signal certification or medical decisions.
The earlier failed logistic model is preserved in development outputs and is
not activated. The model and NASA source attribution do not imply endorsement.
Bundled monitoring demonstrations run offline. Only the explicit Fetch NASA
references action requests the 26 allowlisted public WinSCAT files from NASA;
it verifies their lengths and SHA-256 values and stores a local cache. It sends
no health records, login, credentials or telemetry. The metadata allowlist is
bundled; raw NLSP files are not. Tk provides the local interface
and Canvas plots; Python's
standard library implements replay, JSON validation and local data handling.
