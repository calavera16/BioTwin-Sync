BioTwin Sync - 우주비행사 건강 모니터링
Windows 포터블 해커톤 프로토타입

시작
ZIP 전체를 풀고 BioTwinSync.exe를 실행합니다. _internal을 EXE 옆에
유지하세요. 기본 기능에는 Python 설치, 로그인, API 키, 인터넷이 필요 없습니다.
4단계 안내는 다음으로 넘어갈 때까지 읽을 수 있게 유지됩니다. Back/Next/Finish 또는
Close guide를 사용하세요. Help > Quick guide에서 다시 열 수 있으며
승무원·관찰·세션을 변경하지 않습니다. Help에는 Reduce motion도 있습니다.

세 가지 핵심 영역
Crew overview에서 Crew 001 또는 Crew 002를 엽니다.
1. Your condition: 그래픽 상태와 다음 행동을 먼저 봅니다. View measurements를
   열면 Head / cognition, Heart / signals와 입력한 측정값을 확인합니다.
   Back to condition은 간단한 상태 화면으로 돌아갑니다. Chart help에서
   출처, 축, 음영과 사용 불가 상태의 의미를 확인합니다.
2. Next step: 도우미 또는 Review received steps를 엽니다. 전체 점검 안내는
   스크롤 가능한 별도 창에 표시되며 수행 메모·기록·후속 전송 조작은 아래에 고정됩니다.
   안내용 예제에서는 수행 기록을 할 수 없습니다. 승무원·세션·근거가 바뀌면 이전 메모를 지웁니다.
3. Earth medical link: Crew now와 Earth last received의 값·관찰 시각·자료 경과 시간을
   비교합니다. Earth review를 열면 수신값과
   Messages / Review / References가 나타나며 답변·의료진 작성·과거 자료를
   묶습니다. 지구 화면에는 전달된 근거만 보입니다. Hide Earth review로 닫습니다.

승무원 그림의 표적 또는 옆의 Cognition, NASA recordings, Measurements를 선택합니다.
Alt+H는 인지 기록, Alt+C는 신호 기록을 엽니다. 그림은 메뉴이며 장기 건강 판정이 아닙니다.
체크리스트가 주 행동일 때도 Session > Onboard assistant로 도우미를 열 수 있습니다.
반복적인 그라데이션 행 대신 승무원 그림 주변의 은은한 파란 빛과 공간으로 강조합니다.
주황은 주요 행동을, 밝은 파랑은 관찰을 강조합니다. 초록은 비교 가능한 반응 검사에서
변화가 감지되지 않았다는 뜻입니다. 다른 생체지표의 변화는 여기서 판정하지 않으며
정상·안전·임무 허가를 뜻하지 않습니다. 황색은 검토,
빨강은 보고된 위험, 중립색은 근거 부족을 뜻합니다. 문구와 기호도 함께 표시합니다.
움직임은 실제 화면 변화와 모의 전달을 보여 줍니다. 파형은 Play를 눌러야 재생되며
Reduce motion은 자동 전환 움직임을 줄입니다.

기본 시연
Demo controls를 열고 09:00 Sent → 09:20 Earth → 09:30 Change →
09:40 Guide 순으로 확인합니다. 09:30 승무원 관찰이 바뀌어도 지구에는
과거 수신값이 남고, 09:40 답변 도착 시 조건부 Plan B가 선택됩니다.
자동 재생은 09:40에 멈춥니다. Next extended event로 이후 예제 수행 기록,
반복 측정과 후속 전송을 별도로 확인합니다. 재생·속도·슬라이더는 하나의 시간축에 있습니다.
움직이는 패킷은 모의 전달 상태이며 실제 네트워크가 아닙니다.

Why this result?와 Inspect received snapshot은 출처·관찰 및 수신 시각·품질·
실제 과거 비교 기준을 읽기 쉬운 요약으로 먼저 보여 줍니다. 기술 JSON은 별도로 엽니다.
NASA 파형 배너는 해당 기록이 선택한 승무원의 관찰 자료와 별개임을 표시합니다.

실제 노트북 입력
Session > Local measurements > Start empty local session으로 시작합니다.
작업 중인 세션이 바뀌므로 필요하면 먼저 저장하세요.
Measure에서 수동 생체지표·수면 일지를 기록합니다. 저장 전에 Source,
time & context를 확인하세요. 기본 품질은 review이며 usable은 입력자의
확인입니다. Timed reaction check는 Space 키를 사용하며 취소·포커스 이탈·
미완료 검사는 저장하지 않습니다. WinSCAT나 임무 준비도 검사가 아닙니다.
Signals에서 ECG/BVP JSON, 구간 표시와 재측정 요청을 사용합니다.
Open separate model demo는 NASA 예제 추론을 개인 건강 기록과 분리합니다.
History에는 Export import examples가 있으며 가져오기는 먼저 검증합니다.

승무원 도우미
Next action > Open onboard assistant를 엽니다. Questions에서 증상 경로를
선택하고 Yes/No/Unsure로 답한 뒤 Guidance를 검토하고 Record assessment를
누릅니다. Add a note는 선택 사항이며 자유 메모를 의료 판단으로 해석하지 않습니다.
실제로 수행한 단계만 기록하고 근거가 바뀌면 Reassess를 사용하세요.
수행 완료는 증상 해소가 아니며 이전 위험 징후는 이력에 남습니다.
More에서 출처, 답변·이유, 승무원 이력, 지구 수신 인계서, 모의 통신 조작을
엽니다. Send consultation으로 명시적으로 인계서를 대기열에 넣습니다.
Get urgent help와 위험 징후 표시는 저장·전송 이전에도 작동합니다.
이 프로그램은 구조 요청이나 실제 의료 통신을 수행하지 않습니다.

세션과 의료진 검토
Session에 Save/Open/Export, New operator session, Reset guided scenario가
있습니다. Ctrl+S로 저장하고 Ctrl+O로 엽니다. 가져오기 전에 해당 Crew를
선택하세요. 작업 공간을 바꾸기 전에 저장하며 기존 저장 파일은 유지됩니다.
상담 전송 → 전달 시간 진행 → Earth review > Review > Author Plan A / B →
답변 전달 → 수행 기록 → Send follow-up 순으로 직접 조작할 수 있습니다.
분기 선택은 수행 완료가 아닙니다. 로컬 파일은 2 MiB 제한이며 암호화되지 않습니다.

자료의 의미
합성 임무, 개인 입력, NASA 기록은 출처 표시로 구분합니다. 그래프 음영은
과거 기록의 분포이며 정상·안전 범위가 아닙니다. NASA SOTERIA는 실제
조종사 시뮬레이터 기록으로 실시간 우주비행사 센서가 아닙니다. 각 채널의
시계는 독립이고 진폭 단위는 미확인입니다. 결측값은 사용 불가로 유지하며 추정값을 만들지 않습니다.
수면 일지는 수면 단계 추론이 아닙니다. NASA 학습 포레스트 2개는 실험적
신호 검토 모델입니다. 인위적 손상 균형 정확도는 98.63%, 자연 저자 제외
구간은 44.16%로 실패했으므로 실제 기록은 수동 검토가 필요합니다.
도우미는 출처 기반 규칙이며 학습된 진단 모델이 아닙니다. 임상의 검토·
비행 승인은 아직 없으며 진단·투약·임무 허가를 제공하지 않습니다.
NHS/FDA는 지상용 배경 자료이며 피로 자료의 검토 예정일 경과도 공개합니다.

References > Fetch NASA는 알려진 WinSCAT 공개 파일 26개(28,204바이트)를
선택적으로 내려받아 검증·캐시합니다. 이때만 인터넷이 필요하며 건강자료
업로드·로그인·키·비용은 없습니다. 과거 사례는 검증된 유사 환자가 아닙니다.
원본 NLSP는 ZIP에 없으며 출처는 Help > About / data sources에 있습니다.

자동 검사(새 보고서 경로):
BioTwinSync.exe --smoke-test --report "C:\쓰기 가능한 폴더\smoke.json"
종료 코드 0과 status=passed는 소프트웨어 검사 결과이며 임상·화면 승인이나
다른 컴퓨터 검사를 대신하지 않습니다. ATTRIBUTION.txt와 RUNTIME-NOTICES.txt를
확인하고 평소 Windows 보호 정책을 유지하세요.
