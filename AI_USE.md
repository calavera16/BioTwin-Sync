OpenAI ChatGPT/Codex assisted software implementation, refactoring, tests, debugging, documentation, presentation wording/layout and synthetic demonstration fixtures. AI-assisted code includes the Python backend, React interface, Electron shell and supporting tests/build scripts. Deterministic checks and human-directed review were used; AI assistance is not evidence of clinical validation.

OpenAI image generation created the abstract magenta/coral illustration in the presentation. Every use of that artwork in the submission deck is visibly labeled. App screenshots are captures of the running prototype; NASA source recordings were not generated by AI. App SVG diagrams/icons are code-authored visuals with AI assistance, not NASA branding.

The 420/585 ms cases, illustrative cutoff and delayed-message scenario are synthetic, AI-assisted code fixtures, labeled separately from NASA research data. No real user medical data or identities were used to construct those examples. Generated technical corruption used in experimental signal-model work is separate from unaltered source recordings and is not a disease label.

The delivered application has no live LLM or remote generative-AI dependency. Its conditional evaluator and offline assistant are deterministic; calling them AI-assisted development does not make them clinically validated AI.
